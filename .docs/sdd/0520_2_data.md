## 五、关键结论

1. **Sort 改进效果显著**：合法动作（57%）→ 安全并行（70%）→ 验证层（100%）
2. **Rope 改进同样有效**：50% → 100%（4/4），且仅需 1 步
3. **Baseline pack/sweep/sandwich-plan 全部 0%**，反映这些任务本身对无改进的 LLM 极难
4. `sort_code2_softscore_test_10runs` 全部 crash 是 display 环境问题，xvfb 修复后恢复正常
5. Recovery 机制（90%）略低于纯 verifier（100%），但步数更少（5.4 vs 6.1），在效率上有优势
